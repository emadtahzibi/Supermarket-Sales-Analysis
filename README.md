# Supermarket-Sales-Analysis

## Overview
This project analyzes a supermarket sales dataset using Python to identify key business insights and trends.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Findings
- Food & Beverages was the top-performing product line
- Sales were relatively balanced across all three branches
- Payment methods were evenly distributed between Ewallet, Cash, and Credit Card

## Dataset
Source: Kaggle - Supermarket Sales Dataset
